## Currently Building: MathAlgo

> A learning hub for HCMUS Math & CS students: documents, competitions, projects, articles, member profiles, and a CV builder.
> 🔗 **[mathalgo.com](https://mathalgo.com)**

- Built on **React + Docusaurus** with **Supabase (PostgreSQL)** for auth and data
- Security-first data layer: **row-level security on every table**, column-level grants, and `SECURITY DEFINER` RPCs that never expose user IDs to the browser
- Features: public member profiles, project showcase, articles with LaTeX rendering and view tracking, bilingual (EN/VI) CV builder that stores nothing

**Where it's heading:** CI/CD and tests → AI features (RAG assistant, AI CV review) → automated data pipelines → a recommendation system trained on real usage data.
